CLICK IX — ART DIRECTION, MOTION LEXICON & STORY FLOW
Creative Direction Specification · 16 November 2026 · Next.js 15 / React 19 / GSAP
PLAIN-TEXT EDITION OF THE D1–D4 REPORT

EXECUTIVE DECISION — TEN-LINE SUMMARY
1. Sell operational confidence, not visual effects. The buyer must understand that one team can supply, install, operate and prove digital screen networks.
2. Recommended art direction: Signal Chain. Make the movement from physical screen to software to campaign evidence the site's central visual narrative.
3. Preserve the established identity. Keep the paper/ink/blue palette, existing grotesk, supplied logos, installation photography and current hero.
4. Use one signature motion system. The pixel-cell hero can introduce the brand; a single connected-system transition should carry the main explanation.
5. Make original project photography the primary artifact. Every important visual should demonstrate something the company has actually built or operated.
6. Give each page a different job. Home creates confidence, Product explains capabilities and fit, Case Study demonstrates delivery.
7. Reduce animation density. Native scrolling, intentional pauses and direct interactions should dominate over repeated pins, marquees and automated reveals.
8. Treat software authenticity as a release gate. Use approved real interfaces, or clearly labelled diagrams when those interfaces are unavailable.
9. Build progressively. A complete static page must exist before React, GSAP or any enhanced interaction executes.
10. Ship the buyer narrative first. Aim for LCP below 2.5s, CLS below 0.05, INP below 200ms and WCAG AA without sacrificing clarity.

HOW TO READ
Each entry includes term/aliases; plain gloss; what it communicates; where it belongs; actual implementation; relative performance/effort cost; accessibility fallback; cliché/tell risk; real reference.

COST MODEL
1: performance negligible / effort small CSS or content adjustment.
2: performance limited paint/compositing / effort localized component.
3: performance noticeable media/interaction / effort reusable component and testing.
4: performance sustained animation or larger rendering / effort complex motion/responsive engineering.
5: performance major graphics or media workload / effort specialized pipeline and extensive QA.
Scores are estimates, not measured benchmarks.

ACCESSIBILITY FALLBACK LEGEND
S: All text, links, captions, images and relevant content remain visible without JavaScript.
R: Reduced motion disables decorative transitions and displays final intended content immediately.
P: Pinned/scrubbed scenes become regular vertical content without compulsory scroll progression.
U: Visible keyboard-operable controls exist without hover/drag dependence.
F: Video becomes poster or user-controlled playback; message never depends on motion.
D: Data has accessible text or tabular equivalent.
M: Map includes ordered location list and direct links.
